# C8 — Rabat Geometry Evidence Batch 4

## Goal

Qualifier la preuve spatiale disponible pour Diour Jamaa sans confondre existence d'une géométrie autoritative et droit de réutilisation commerciale.

## Verdict

### Diour Jamaa — GEOMETRY UNRESOLVED / RIGHTS-BLOCKED

Le Centre du patrimoine mondial de l'UNESCO identifie `Quartier Habous de Diour Jamaâ` comme composante **1401-003** du bien de Rabat, avec une superficie de **3,78 ha** et des coordonnées publiées. Une carte officielle du bien inscrit est également référencée.

Cette preuve confirme fortement l'existence d'une emprise spatiale autoritative. Elle ne suffit toutefois pas à importer cette emprise dans AkarFinder : les conditions UNESCO/WHC imposent une permission/licence pour la republication ou syndication commerciale de leurs données.

## Garde-fous

- aucun KML UNESCO copié ;
- aucun polygone UNESCO copié ou retracé ;
- aucune frontière dérivée d'une image ou d'un PDF ;
- aucun buffer de centroïde/Voronoi/substitution administrative ;
- `geometry_unresolved` conservé ;
- aucune écriture production ;
- aucune activation publique.
