# C8 — Rabat Taxonomy Evidence Batch 4

## Goal

Qualifier un nouveau candidat C8B uniquement si une source institutionnelle de premier rang l’identifie explicitement comme quartier de Rabat.

## Décision

### Diour Jamaa — READY FOR TAXONOMY CERTIFICATION

Dans une communication officielle consacrée au patrimoine de Rabat, la Commune de Rabat cite explicitement le `quartier Habous Diour Jamaa` parmi les biens et secteurs patrimoniaux de la ville.

Cette formulation établit une identité de quartier suffisante pour la couche taxonomique produit. Elle ne fournit aucune géométrie certifiée et ne vaut pas validation d’autorité DB.

## Non-promotion par cette preuve

- Hay Nahda reste candidate : aucune formulation institutionnelle explicite de quartier n’a été certifiée dans ce batch.
- Oudayas reste candidate : la source officielle qualifie la Casbah des Oudayas comme site patrimonial/noyau historique, pas avec la même preuve explicite de quartier produit.
- Mellah reste candidate : aucune formulation institutionnelle explicite de quartier n’a été certifiée dans ce batch.

## Garde-fous

- evidence-only ;
- aucun changement du registre canonique ;
- aucune géométrie ;
- aucune validation d'autorité DB ;
- aucune éligibilité carte/SEO ;
