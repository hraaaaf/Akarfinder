# UX/UI Certification

## Purpose
Certifier l'expérience réelle, pas seulement la conformité technique, sur les formats pertinents.

## When it applies
Frontend, composants, navigation, Search UX, Map, styles, responsive, accessibilité ou toute sortie visuelle interactive.

## Required inspection
Design system, flux utilisateur, états loading/empty/error, mobile/tablette/desktop, accessibilité, contenu FR/AR/RTL si touché, contraintes Geo/Search/DATA sous-jacentes.

## Mandatory evidence
Captures réelles des états pertinents ; **430×932 obligatoire pour le web responsive**, complétée selon scope par 390×844, 768×1024, 1280×900 ; tests/a11y ; inspection humaine ; score motivé ; findings severity.

## Blockers
Tout finding critical/high ; collision/overflow ; action trompeuse ; données visuelles inventées ; capture absente ; score ≤9.0 ; score fondé uniquement sur tests automatisés.

## PASS / FAIL criteria
PASS uniquement si score final **strictement >9.0/10**, preuves observées, aucun blocker et parcours touchés cohérents. ≤9.0 = `CHANGES_REQUIRED`.

## Forbidden shortcuts
Pas d'auto-note ; pas de capture après manipulation artificielle non représentative ; pas de “premium” sans inspection ; pas de validation desktop seule.

## Required final report
SHA, routes/états, viewports, captures/artifacts, a11y, findings, score par axes si utile, score final et verdict.
